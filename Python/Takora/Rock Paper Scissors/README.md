# Assignment - Rock, Paper, Scissors

<u>Requirement Statement:</u> Write a Python program to allow the user to play Rock, Paper, Scissors with the computer. Ask the user to enter a number (1 for Rock, 2 for Paper, 3 for Scissors). The computer shall then make its choice by generating a random number between 1 and 3. Print what the user chose and what the computer chose. Print the outcome of the round. Keep playing until the user wins.
